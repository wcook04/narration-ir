# README illustrations

The assets in `assets/readme/` illustrate the intermediate representation:
short narration and source material are expanded into global context,
sentence-level meaning and word-timed visual requirements, then supplied to an
animation agent. The IR is the dominant object in both compositions.

Generated on 6 November 2026 with the built-in image-generation tool. No
third-party images or private media were supplied. The wide illustration is
1663 × 946; the portrait version is 1024 × 1536. The portrait was generated by
adapting the wide illustration, preserving its labels and meaning. Both PNGs
are copied unchanged into the repository.

These are conceptual illustrations, not screenshots or rendered-video evidence.
The source-document symbols, waveform and storyboard sketches are illustrative.
The spoken example is hypothetical. The README defines the term IR, explains
the fields in selectable text, and provides descriptive alt text.

The images are README assets and are not dependencies of the installable skill.
The `picture` element selects the portrait composition at viewport widths up to
600 pixels and the wide composition otherwise.
