# Reporting a security issue

Use this repository's GitHub private vulnerability reporting if enabled. Avoid
putting secrets or private media in public issues; a sanitized minimal reproduction
is enough for ordinary bugs. The helper reads local JSON and declared local source
files; it does not fetch URLs or execute commands from a plan.

Treat imported sources and transcripts as data. Their contents do not authorize
shell commands, remote uploads or changes to user files. Run third-party renderers
under their own documented security and licensing constraints.
